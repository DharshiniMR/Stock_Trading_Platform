# Zerodha Clone 🚀

A full-stack UI clone of the Zerodha trading platform built using React. This project replicates a real-world trading experience with a landing page and dashboard UI using a component-based architecture.

---

## 📌 Features

- Responsive Zerodha-inspired landing page
- Trading dashboard UI
- Modular and reusable components
- Organized multi-folder structure (frontend + dashboard)
- Mock data integration for UI simulation
- Clean and responsive design

---

## 🧱 Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Node.js

---

## 📁 Project Structure

frontend/ → Landing page + UI  
dashboard/ → Trading dashboard UI  
assets/ → Images and static files  
data/ → Mock data  

---

## 🚀 Getting Started

### Clone the repository

git clone [https://github.com/DharshiniMR/Stock_Trading_Platform.git]

### Install dependencies and run frontend

cd frontend  
npm install  
npm start  

### Install dependencies and run dashboard

cd dashboard  
npm install  
npm start
